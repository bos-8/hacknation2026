W module CSS czatu klasa generowana przez `remark-gfm` jest dopasowywana przez `li[class~="task-list-item"]` wewnątrz kontenera Markdown. Poprzedni zapis z `:global()` powodował ostrzeżenie parsera podczas kompilacji DEV. Po zmianie `/pl/chat` zwróciło HTTP 200 przez HTTPS, a wygenerowany arkusz zawierał selektor atrybutu.
