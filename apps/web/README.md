# FORMIQ Web

Next.js workspace application with PL/EN, shared UI, theme and contrast controls.

Use root commands from the repository directory:

```powershell
pnpm dev
pnpm check
pnpm build
pnpm start
```

See [Web foundation](../../docs/0204-web-foundation.md) for implementation scope
and [workspace commands](../../docs/0205-workspace-commands.md) for the full command
reference. Better Auth is installed; authentication integration remains pending.
