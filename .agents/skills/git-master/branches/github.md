# GitHub

Confirm the repository owner/name and requested base/head from the actual remote
or connected repository. Do not infer public/private visibility or change it.

| Request | Read |
| --- | --- |
| Workflows, job triggers, permissions or checks | [GitHub Actions](../references/github-actions.md) |
| Pull request, review, merge or repository delivery | [Pull requests](../references/github-pull-requests.md) |

For accompanying local commits/pushes, use the Git workflow and shared Messages
leaves. A PR draft does not authorize merging or deployment.
