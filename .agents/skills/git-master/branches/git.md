# Git

Use for local version-control work and transport to an already identified remote.

- Commit, staging, branch/merge or push operations: read
  [Git workflow](../references/git-workflow.md).
- Message-only requests: read [Messages](../references/messages.md) directly.

Choose the GitHub/GitLab branch only when the task needs hosting-specific behavior;
a local repository may have neither host, or more than one remote.
