# GitLab

Confirm the GitLab instance, project path and requested source/target branches.
For self-managed installations, check that instance's supported features/version.

| Request | Read |
| --- | --- |
| Pipeline YAML, runners, rules or CI variables | [GitLab CI](../references/gitlab-ci.md) |
| Merge request, review, merge or repository delivery | [Merge requests](../references/gitlab-merge-requests.md) |

For accompanying local commits/pushes, use the Git workflow and shared Messages
leaves. A merge request does not authorize merging or deployment.
