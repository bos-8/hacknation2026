# GitHub Pull Requests

- Confirm owner/repository, base/head and the full proposed diff; reuse a matching
  existing PR rather than creating duplicates.
- Lead the body with the resulting behavior and include actual checks and material
  limitations. Use [Messages](./messages.md) for a commit/squash title when needed.
- Inspect required checks, review requests, conflicts and branch protections.
  Merge only within the user's authorization, using the repository's merge policy.
- Keep PR creation, merge, release publication and deployment as distinct actions.
  Report the PR URL and real check/merge state; do not change protections to unblock it.
