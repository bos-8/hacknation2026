# Tester Strategy

Choose the smallest useful validation path before writing or running tests.

## Use When

- The request is about testing, verification, validation, or QA in general.
- The user asks what depth of testing is appropriate.
- The task spans both test selection and test authoring.

## Selection

Use the root's core rules. Choose `references/impact-selector.md` for scope, `references/runtime-validation.md` for checks, or `references/test-authoring.md` for regression coverage. Load only the needed workflow.
